## 1. 知識地圖組織與孤立節點整合
在 `INDEX.md` 的「其他知識節點」中，發現有許多條目僅以清單方式表列，缺乏上下文脈絡，讀者無法從知識地圖的分類中循序漸進地探索。
為了在執行限制內完成具體改善，本次將挑選以下 3 個節點進行知識地圖的整合，將它們移入合適的分類並給予脈絡描述：
- [x] 將 `[[矽光子]]` 移入「進階記憶體與封裝 (高階)」分類，作為解決未來資料中心頻寬極限的延伸閱讀。
- [x] 將 `[[小晶片]]` 移入「進階記憶體與封裝 (高階)」分類，作為突破單一晶片面積限制的技術。
- [x] 將 `[[SIMT]]` 移入「硬體架構 (中階)」分類，作為 GPU 執行緒層級架構的延伸。

## 2. 內容過少與缺乏說明的頁面補充
經過掃描發現，上述 3 個檔案（`矽光子.md`, `小晶片.md`, `SIMT.md`）目前僅包含由樣板生成的佔位文字（如「方案一：基於現有框架...」），未能提供讀者需要的背景知識與專業解釋。
根據指示，已觸發虛擬團隊（研究員、教育員）針對這些檔案進行重新撰寫，將詳細的技術內容轉化為易讀的形式：
- [x] 擴充 `content/矽光子.md`，提供深入的技術原理（例如光電轉換）、應用於 AI 互連的原因，以及實際的優缺點分析。
- [x] 擴充 `content/小晶片.md`，解釋 Chiplet 的概念、良率優勢、先進封裝（如 CoWoS）的搭配，以及為何 AI 加速器需要它。
- [x] 擴充 `content/SIMT.md`，詳細解說單指令多執行緒（Single Instruction, Multiple Threads）架構、Warp/Wavefront 概念，以及它與傳統 SIMD 的差異。
