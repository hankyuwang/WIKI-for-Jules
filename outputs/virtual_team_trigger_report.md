## 虛擬團隊協作流程紀錄

1. **維護員 (Maintainer)**
   - **發現問題**：偵測到指向 `[[深度學習運算原理]]` 的失效連結。
   - **處置建議**：觸發多 Agent 虛擬團隊流程，補充相關基礎知識。

2. **接待員 (Receptionist)**
   - **需求釐清**：確認需新增 `深度學習運算原理.md`。
   - **目標**：提供深度學習底層數學與運算架構的基礎觀念。
   - **限制**：內容需涵蓋基本概念及 3 種架構層面的觀點/解決方案，並包含各方案的優缺點、成本、維護性與風險。

3. **知識架構師 (Knowledge Architect)**
   - **檔案層級**：定義為 `beginner`。
   - **分類與標籤**：設定適當的 `tags` (如：DeepLearning, Architecture)。
   - **大綱設計**：
     - YAML frontmatter
     - 摘要
     - 核心運算概念 (矩陣運算、活化函數等)
     - 三種硬體架構實作方案評估
     - 相關 WikiLink 互相連結

4. **研究員 (Researcher)**
   - **知識探索與產出**：深入研究深度學習運算的底層原理，並針對如何高效執行這些運算，提出三種不同的硬體架構觀點（純軟體/通用處理器、高度平行處理器、專用加速器）。
   - **方案分析**：詳細比較上述三種方案的優缺點、成本、維護性與風險。

5. **驗證員 (Validator)**
   - **事實查核**：確認研究員提出的運算原理與硬體架構觀點無誤，符合現有產業認知。
   - **連結測試**：確保 `[[深度學習運算原理]]` 在新增後能夠正確無誤地被其他頁面引用。

6. **教育員 (Educator)**
   - **內容轉譯**：將研究報告轉換為易於理解的 Markdown 格式，調整語氣使其適合 `beginner` 學習，並加上清晰的標題與條列。
