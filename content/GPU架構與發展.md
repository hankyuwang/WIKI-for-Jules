# GPU 架構與發展

**摘要：**
圖形處理器（GPU）最初設計用於處理圖形渲染，但其高度平行的架構使其成為現代人工智慧（AI）與深度學習模型訓練和推理的核心加速器。隨著 AI 模型規模的指數級增長，GPU 架構也在不斷演進，引入了專門的 Tensor Core、擴展了記憶體頻寬，並發展出各種多 GPU 互連技術以應對巨量資料的運算需求。本篇將探討 GPU 應用於 AI 運算的三種主要發展視角與解決方案。

## 觀點與解決方案

### 1. 單一高效能 GPU 擴展 (Scale-Up)
透過持續微縮製程技術與架構創新，在單一晶片上整合更多的運算單元（如 CUDA Cores、Tensor Cores）與更大容量的快取與高頻寬記憶體（如 [[HBM高頻寬記憶體技術]]）。

*   **優點 (Pros)：** 開發模型相對簡單，不需要複雜的分散式訓練策略；單一節點內的資料傳輸延遲最低，運算效率最高。
*   **缺點 (Cons)：** 受到摩爾定律放緩與光罩尺寸（Reticle Limit）的限制，單一晶片效能提升的難度與成本急劇增加；散熱與功耗（TDP）挑戰極大。
*   **成本 (Costs)：** 研發與製造成本極高，單張頂級 AI GPU 的售價非常昂貴。
*   **維護性 (Maintainability)：** 硬體維護相對單純，但系統層級的散熱與供電設計需求極高。
*   **風險 (Risks)：** 供應鏈高度集中（如依賴台積電先進製程與 CoWoS 封裝），一旦供應鏈中斷將面臨嚴重的斷貨風險。

### 2. 多 GPU 叢集互連 (Scale-Out)
將多張 GPU 透過高速互連技術（如 NVLink、InfiniBand、RoCE）組成龐大的運算叢集，以分散式訓練技術處理超越單一 GPU 記憶體容量與算力極限的超大型模型。

*   **優點 (Pros)：** 算力擴展性極佳，是目前訓練千億參數以上超大語言模型的唯一可行方案；容錯性較高，叢集內部分節點故障可透過排程繞過。
*   **缺點 (Cons)：** 網路通訊開銷大，若互連頻寬不足容易造成效能瓶頸（Communication Bottleneck）；軟體層面需要複雜的平行化策略（如 Data, Tensor, Pipeline Parallelism）。
*   **成本 (Costs)：** 需要投入大量資金建置高速網路基礎設施、資料中心空間與龐大的電力供應。
*   **維護性 (Maintainability)：** 叢集管理與排程複雜，需要專業的 MLOps 團隊與分散式系統維護人員。
*   **風險 (Risks)：** 網路拓撲設計不當可能導致嚴重的效能損耗；軟硬體協同優化難度高。

### 3. 基於 Chiplet 技術的模組化 GPU 架構
有別於傳統的單晶片（Monolithic）設計，利用先進封裝技術，將多個功能模組（小晶片）整合在同一封裝內，這也是未來 [[Chiplet小晶片技術]] 在 GPU 領域的重要應用方向。

*   **優點 (Pros)：** 突破單一晶片面積限制，顯著提高良率（小晶片良率高）；可以混搭不同製程節點的模組以優化成本與效能。
*   **缺點 (Cons)：** 封裝技術難度高，需要解決 Chiplet 之間的高頻寬與低延遲通訊問題（Die-to-Die Interconnect）；整體功耗與散熱管理更加複雜。
*   **成本 (Costs)：** 雖然晶片製造成本降低（良率提升），但先進封裝（如 2.5D/3D 封裝）的成本仍然很高。
*   **維護性 (Maintainability)：** 設計複雜度轉移至封裝與系統級測試，對封裝良率的依賴度極高。
*   **風險 (Risks)：** 先進封裝產能若不足，將直接限制這類模組化 GPU 的出貨量；新的 D2D 互連標準（如 UCIe）仍在發展中。

## 摘要
圖形處理器（GPU）最初設計用於加速圖像渲染，但憑藉其高度平行的運算架構，現已成為人工智慧與高效能運算（HPC）的核心硬體。GPU 透過大量的串流多處理器（Streaming Multiprocessors, SMs）同時處理巨量數據，特別適合深度學習中的矩陣乘法等計算密集型任務。本篇筆記將探討 GPU 架構的發展及其在 AI 領域的應用視角。
## 三種視角與方案探討
### 1. 通用 GPU (GPGPU) 運算架構
**優點：** 高度靈活性與廣泛的軟體生態系統（如 CUDA, ROCm），支援各種深度學習框架（TensorFlow, PyTorch）。
**缺點：** 功耗較高，且並非所有電晶體都專用於 AI 運算（部分仍保留圖形處理能力）。
**成本：** 硬體採購成本極高，尤其是在資料中心等級的高階 GPU（如 NVIDIA A100, H100）。
**維護性：** 由於有強大的開發者社群與廠商支援，軟體與驅動程式維護相對容易，更新頻繁。
**風險：** 供應鏈限制可能導致硬體短缺；同時對特定廠商（如 NVIDIA）產生強烈的生態系依賴。
### 2. 專注 AI 加速的 Tensor Core 架構
**優點：** 針對深度學習的混合精度運算（如 FP16, INT8）進行硬體層面優化，大幅提升運算吞吐量。與 [[模型量化技術]] 搭配時效果顯著。
**缺點：** 僅對特定類型的矩陣運算有極大加速，對於非張量運算的通用邏輯處理幫助有限。
**成本：** 研發與製造成本高，反映在終端產品售價上。需要搭配高頻寬記憶體（如 [[高頻寬記憶體_HBM]]）才能發揮最大效能。
**維護性：** 需要開發者熟悉並利用特定 API 或依賴底層函式庫（如 cuDNN）才能完全發揮硬體性能。
**風險：** 隨著 AI 演算法（如稀疏性、非矩陣乘法主導的架構）快速演進，過度硬體硬體化的 Tensor Core 可能面臨彈性不足的風險。
### 3. 多 GPU 與分散式訓練架構
**優點：** 透過 NVLink 或 PCIe 擴展，解決單一 GPU 記憶體與算力瓶頸，支援超大型語言模型（LLM）的訓練。
**缺點：** 系統複雜度呈指數級上升，節點間的通訊延遲可能成為新的效能瓶頸。
**成本：** 不僅是多張 GPU 的成本，還包含昂貴的網路互連設備（如 InfiniBand）與散熱、供電基礎設施。
**維護性：** 分散式系統的除錯與效能調優非常困難，需要專業的基礎架構工程團隊維護。
**風險：** 軟硬體協同失敗可能導致資源閒置（低 GPU 使用率）；硬體故障的機率隨規模擴大而增加。
