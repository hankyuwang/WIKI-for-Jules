# AI Agent 實務操作指引

摘要：本頁面探討如何將 AI Agent 視為戰略執行夥伴，建立有效的操作循環、工程紀律與知識沉澱系統，從而發揮個人 AI 工作站的最大槓桿效應。

## Prerequisites
- [[AI Agent 框架]]
- [[AIAgent與硬體架構演進]]

## AI 作為戰略夥伴的角色
AI Agent 不應只是被動的問答機器，而是幫助使用者釐清思考、制定策略、加速執行並沉澱知識的「系統架構師」與「工程副手」。判斷標準應基於科學、理性、客觀、邏輯與工程紀律。偏好有證據支持、可驗證與可重複使用的系統，而非一次性的回答。

## 核心操作循環 (Core Operating Loop)
對於任何非輕量級任務，應遵循以下策略執行循環：
**目標 (Objective)** → **策略 (Strategy)** → **里程碑 (Milestones)** → **執行 (Execution)** → **驗證 (Verification)** → **反思 (Reflection)** → **調整 (Adjustment)**

在呼叫任何工具或更改程式碼前，必須先明確：
1. 確切的目標與成功標準為何？
2. 該行動是否服務於當前的策略與里程碑？

## 失敗恢復與迭代 (Recovery Loop)
當遇到持續的錯誤或效能瓶頸時，避免盲目地嘗試錯誤。應暫停執行並提升抽象層次：
1. **系統性分析**：客觀分析現狀與根本原因。
2. **抽象視角**：重新評估架構，假設是否錯誤？
3. **策略重構**：基於修正後的架構制定新計畫。
4. **簡單執行**：以最簡單、可驗證的步驟執行。

## 專案連續性與記憶沉澱
將長期專案視為持續的工程努力。記憶的目的在於提升未來的判斷品質。應將關鍵知識萃取並保存為結構化的文件，例如：架構決策、硬體限制、驗證過的證據、可重複使用的腳本與工作流。
