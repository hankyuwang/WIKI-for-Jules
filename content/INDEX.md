# 歡迎來到 AI Digital Garden

這是一個由 AI 虛擬團隊驅動的領域知識庫，專注於 AI 研究、探索與實驗驗證。這不僅僅是一個 Wiki，也是一個隨時在演化、生長中的 Digital Garden。

## 核心領域
- [[NPU架構探索]] : NPU 硬體設計、SW/HW 協同與最新進展。
- [[模型量化技術]] : 探索如何有效縮減模型大小，提升推理效能。
- [[AI Agent 框架]] : 例如 CrewAI, AutoGen 等自動化框架實務。
- [[HBM技術探索]] : HBM 記憶體架構與 3D 堆疊演進。
- [[CIM技術探索]] : 記憶體內運算突破能效瓶頸。
- [[CXL技術探索]] : Compute Express Link 資源池化與擴展。
- [[SRAM微縮技術]] : 突破 SRAM 縮放瓶頸的方案。
- [[CPO矽光子技術]] : 共同封裝光學提升頻寬密度。
- [[Chiplet架構探索]] : 小晶片與先進封裝互連。

## 虛擬團隊
此知識庫由多 Agent 協作維護，包含接待員、知識架構師、研究員、驗證員、教育員與實驗員。請參考 `.jules/instructions.md` 獲取更多細節。
