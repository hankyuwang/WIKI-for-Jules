# FP16

摘要：FP16 是 16位元浮點數格式，廣泛應用於深度學習中的混合精度訓練與推理，能有效節省記憶體頻寬並加速運算。

## 五分鐘版
FP16 (Half-precision floating-point) 將傳統的 32位元浮點數 (FP32) 縮減至 16位元，包含 1 bit 符號位、5 bits 指數位以及 10 bits 尾數位。它在深度學習中常與 FP32 結合使用（混合精度訓練），在不損失模型精度的前提下，將記憶體消耗減半，並提高 Tensor Core 等專用硬體的運算吞吐量。

## 完整版
### 已知事實與原理
深度學習模型的權重和激活值通常不需要 32位元的極高精度。FP16 提供了足夠的動態範圍和精度來表示大部分網路參數。在訓練時，通常會保留一份 FP32 的主權重 (Master Weights) 來進行權重更新，而前向傳播 (Forward Pass) 與反向傳播 (Backward Pass) 的矩陣乘法則使用 FP16 進行，這稱為混合精度訓練 (Mixed Precision Training)。

### 限制與邊界條件
FP16 的最大缺點是其動態範圍較窄（最大值約 65504），容易發生溢出 (Overflow) 或下溢 (Underflow)。這通常需要引入 Loss Scaling 技術，在反向傳播前將損失值放大，以防止梯度變為 0。

### 未知問題與前沿
目前業界正在探討 FP16 與 BF16 (Bfloat16) 的優劣。BF16 犧牲了尾數精度，換取了與 FP32 相同的動態範圍（8 bits 指數位），在訓練 LLM 時越來越受歡迎。

## 方案與觀點分析 (硬體層面)

### 方案一：標準 GPU Tensor Core 支援
- 優點：生態系統成熟，PyTorch 等框架提供一鍵式 (AMP) 支援。
- 缺點：依賴高價的商用 GPU 晶片。
- 成本：中等（設備採購成本）。
- 維護性：極高。
- 風險：在某些對精度極度敏感的任務中可能導致模型發散。

### 方案二：自研 ASIC (如 TPU) 針對 FP16 最佳化
- 優點：可以針對特定的矩陣乘法設計超大型脈動陣列 (Systolic Array)，實現極致的 TOPS/W 能效。
- 缺點：缺乏泛用性，且需自行維護編譯器生態。
- 成本：極高（NRE 成本）。
- 維護性：低。
- 風險：晶片設計週期長，硬體規格定型後難以更改。

### 方案三：FP16 與 BF16 動態混合架構
- 優點：硬體同時支援兩種 16-bit 格式，編譯器根據張量的數值分佈動態選擇。
- 缺點：晶片面積增加，且控制邏輯複雜。
- 成本：高。
- 維護性：中等。
- 風險：調度演算法複雜，可能帶來額外的延遲 overhead。
