# GPU在AI加速的應用

摘要：圖形處理單元（Graphics Processing Unit, GPU）起初設計用來處理電腦圖形。由於其高度平行的架構，GPU 如今已成為人工智慧（AI）領域中，特別是深度學習訓練與推理的主力硬體。

## Prerequisites (先備知識)
- [[基礎計算機結構]] : 了解 CPU 與記憶體的基本互動。
- [[AI加速晶片概述]] : 對 AI 加速器有宏觀認識。

## 為什麼 GPU 適合 AI？
傳統的 CPU 擁有少數幾個為複雜序列任務優化的核心，而 GPU 則擁有數以千計的較小、較簡單的核心。這種架構被稱為 **[[SIMT]] (Single Instruction, Multiple Threads, 單指令多執行緒)**。
深度學習的神經網絡（如 [[CNN]]）底層本質上是大量的「矩陣乘法」。SIMT 架構非常適合處理這類可以分解成許多小區塊並同時平行運算的數學問題。

## GPU 在 AI 中的主要優勢
1. **強大的平行運算能力**：數以千計的核心同時運算，顯著縮短模型訓練時間。近代 GPU 甚至加入了專注於矩陣乘加的張量核心 (Tensor Core)。
2. **高頻寬記憶體**：AI 模型訓練存在嚴重的「記憶體牆」問題（數據搬運速度跟不上運算速度）。因此，現代 AI GPU 通常配備 **[[高頻寬記憶體_HBM]]**，以提供極高的資料吞吐量。
3. **成熟的軟體生態系統**：如 NVIDIA 的 [[CUDA]] 平台，提供了豐富且高度最佳化的底層函式庫，建立了極高的護城河。

## 挑戰與未來發展
儘管 GPU 在 AI 領域佔據主導地位，但面臨高耗電量和散熱問題。因此，對於更專精、更高能效的架構，如 [[TPU技術解析]] 或是適用於終端設備的 [[邊緣運算AI晶片]]，需求日益增加。
