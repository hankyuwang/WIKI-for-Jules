# GPU運算架構

> GPU (Graphics Processing Unit) 最初是為了處理圖形渲染而設計，但其高度平行的架構使其成為現代 AI 運算的核心。

## 初學者導覽：把 GPU 想像成一家超級工廠
如果說 CPU 像是幾位擁有博士學位的高階主管，能夠處理非常複雜、具高度邏輯判斷的任務（例如作業系統調度、網頁瀏覽器執行），那麼 **GPU 就像是一個擁有成千上萬名工人的超級工廠**。

這些工人（核心，Cores）雖然無法解決太複雜的邏輯難題，但如果讓他們「同時」做非常簡單、重複性的工作（例如計算圖片中每一個像素的顏色，或是神經網路中龐大的矩陣相乘），他們能夠在極短的時間內完成。這就是所謂的 **平行運算 (Parallel Computing)**。

## 為什麼 AI 需要 GPU？
在深度學習中，我們最常遇到的操作就是 **矩陣乘法 (Matrix Multiplication)**。
當我們訓練一個模型（例如 ChatGPT）時，需要調整數十億個參數，這背後涉及海量的基本數學運算。
- **CPU** 每次只能處理少數幾個數據。
- **GPU** 一次可以同時計算數千到數萬個數據。

這就是為什麼在 AI 時代，GPU 成為了不可或缺的加速器。

## 核心技術概念
要深入理解 GPU，您需要了解以下幾個核心概念：
1. **[[SIMT]] (單指令多執行緒)**：GPU 的運作方式是讓多個執行緒同時執行相同的指令，但處理不同的數據。
2. **[[CUDA]]**：NVIDIA 開發的平行運算平台與程式設計模型，是目前軟體與 GPU 硬體溝通的標準橋樑。
3. **[[Tensor Core]]**：專門為深度學習設計的硬體單元，可以極快地執行矩陣相乘與累加。

## GPU 的記憶體階層 (Memory Hierarchy)
就像一個組織嚴密的軍隊，GPU 內部也有層次分明的資料儲存機制，確保運算效率：
1. **Registers (暫存器)**：工人口袋裡的筆記本，速度最快，但容量極小，專屬於單個執行緒。
2. **Shared Memory (共享記憶體)**：工廠小隊（Thread Block）共用的白板，速度極快，能讓同個小隊的工人快速交換數據，是優化效能的關鍵。
3. **Global Memory / HBM (全域記憶體)**：工廠旁的大型倉庫，容量最大（高達數十至數百 GB），但讀取速度相對較慢。這也就是為什麼需要 HBM 等技術來加速倉庫與工廠間的運輸。

## 從工人到小隊：Warp 與 Thread Block
在 GPU 這個超級工廠中，工人並不是單打獨鬥的：
- **Warp**：最小的作戰單位（通常是 32 個工人），他們像是一支整齊劃一的儀隊，同時接收同一個指令（[[SIMT]]），並對不同的資料採取完全相同的動作。
- **Thread Block**：由數個 Warp 組成的小隊，他們共享一塊 Shared Memory，可以合力完成較為複雜且需要互相協作的任務。

## 為什麼 Transformer 模型如此依賴 Tensor Core？
傳統的運算單元一次只能做一次乘法與加法。而巨型語言模型（如 [[Transformer]]）的底層全都是龐大的矩陣相乘運算。[[Tensor Core]] 就像是一台專為矩陣打造的「超級沖壓機」，在一個時鐘週期內，能一口氣完成一個 4x4 甚至更大矩陣的乘累積加（[[MAC]]），效能是傳統核心的數十倍。這也是為什麼現代 GPU 成為訓練 AI 的不二之選。
