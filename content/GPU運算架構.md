# GPU運算架構

摘要：探討現代 GPU 架構在 AI 訓練與推論上的演進，並分析針對深度學習工作負載的三種架構優化方案。

## Prerequisites
- [[基礎計算機結構]]
- [[AI加速晶片總覽]]

## 解決方案與架構比較

### 方案一：傳統 SIMT 架構優化
利用 GPU 既有的 Single Instruction, Multiple Threads (SIMT) 架構，進一步擴充暫存器大小並提高快取頻寬，以適應神經網路中大量平行的純量運算。

* **優點**: 保持最大的通用性，能直接相容既有的繪圖或傳統科學運算程式。
* **缺點**: 對於深度學習核心的矩陣相乘 (GEMM) 運算，純 SIMT 架構的硬體使用率不如預期。
* **成本**: 矽面積成本較高，因為需要保留許多通用控制單元。
* **維護性**: 高，軟體堆疊極為成熟。
* **風險**: 在面對專用 AI 加速器時，能效比 (Performance/Watt) 處於劣勢。

### 方案二：引入 Tensor Core 硬體單元
在 GPU 的 Streaming Multiprocessor (SM) 中加入專為矩陣乘法設計的硬體單元（如 NVIDIA Tensor Core 或 AMD Matrix Core），支援混合精度運算 (FP16, BF16, INT8)。

* **優點**: 大幅提升矩陣乘法的吞吐量，極大地加速 AI 模型訓練與推論。
* **缺點**: 犧牲了部分晶片面積給專用單元，軟體需要重新編寫或依賴特定函式庫（如 cuDNN）才能發揮效能。
* **成本**: 設計複雜度增加，晶片製造成本上升。
* **維護性**: 中至高，硬體廠商通常會提供優化好的函式庫。
* **風險**: 硬體設計若未跟上最新數值格式 (如 FP8)，可能會有短暫的落後。

### 方案三：記憶體頻寬與互連技術優化
為了解決 "Memory Wall" 問題，GPU 架構大量採用高頻寬記憶體 (參見 [[HBM記憶體技術]])，並開發如 NVLink 的高速互連技術，以建立多 GPU 叢集。

* **優點**: 打破記憶體頻寬瓶頸，實現超大型語言模型 (LLM) 的跨節點訓練。
* **缺點**: 系統層級的設計極度複雜，散熱與供電挑戰巨大。
* **成本**: 系統建置成本極端昂貴（包含 HBM 與高速網通設備）。
* **維護性**: 低至中，叢集級別的除錯與維護需要極專業的團隊。
* **風險**: 互連技術標準封閉，容易造成廠商鎖定 (Vendor Lock-in)。
