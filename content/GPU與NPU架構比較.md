# GPU 與 NPU 架構比較

在 [[AI加速晶片概覽]] 中我們提到，GPU (Graphics Processing Unit) 和 NPU (Neural Processing Unit) 是目前推動 AI 發展最核心的兩種運算硬體。雖然它們都能用來加速深度學習，但它們在設計哲學、架構特徵和適用場景上有著本質上的差異。

## GPU：極致的並行運算與高度通用性
GPU 最初是為了解決圖形渲染中大量且獨立的像素計算而生。
- **SIMT 架構 (單指令多執行緒)**: GPU 擁有多達數千個簡單的運算核心 (ALU)，並採用 SIMT 架構。這意味著它可以同時執行成千上萬個執行緒，非常適合處理高度平行的任務，如巨型矩陣相乘。
- **優勢 - 通用性與生態系**: GPU 最大的優勢在於其**通用性**。它可以靈活應對各種結構迥異的神經網路模型，甚至是傳統的科學運算。同時，憑藉著如 CUDA 般成熟度極高的軟體生態系，開發者能極快地將新演算法部署到 GPU 上。
- **挑戰**: 為了維持通用性，GPU 內部保留了大量的控制邏輯、複雜的快取階層和排程器。在執行單一且重複的神經網路運算時，這些設計反而會成為功耗的負擔，導致能效比 (Performance per Watt) 受限。在深度學習訓練階段，GPU 憑藉強大浮點算力與 HBM 記憶體，依然是無可取代的霸主。

## NPU：專注於神經網絡的領域特定架構 (DSA)
相比之下，NPU (如 Google 的 TPU 或是 Apple 的 Neural Engine) 是專門為神經網路運算而生的客製化硬體，屬於領域特定架構 (Domain-Specific Architecture)。
- **脈動陣列 (Systolic Array) 架構**: NPU 摒棄了 GPU 複雜的控制邏輯，針對深度學習中最常見的乘加運算 (MAC) 進行了高度優化。通常採用脈動陣列架構，資料在密集的運算單元之間直接流動，大幅減少了對暫存器和快取的存取次數，這從根本上緩解了資料搬移造成的延遲與功耗。進階探討可參考 [[NPU架構探索]]。
- **優勢 - 極致能效**: 在特定任務上，NPU 能以遠低於 GPU 的功耗達成相同的吞吐量，這使得 NPU 成為智慧型手機、物聯網設備等邊緣運算場景的首選。
- **挑戰**: 缺乏靈活性。當 AI 演算法發生重大變更（例如從 CNN 轉向 Transformer），高度固化的 NPU 架構可能無法有效支援新的運算模式，導致硬體快速過時。

## 綜合比較與市場分工
- **通用性**: GPU 遠高於 NPU。
- **能效比 (Performance/Watt)**: NPU 在其專屬任務上顯著優於 GPU。
- **主要應用場景**:
  - **GPU**: 雲端資料中心的大規模模型訓練 (Training) 以及複雜多變的推論任務。
  - **NPU**: 終端裝置 (手機、自駕車) 的低功耗邊緣推理 (Edge Inference)，以及雲端大廠 (如 AWS Inferentia) 針對特定模型優化以降低總擁有成本 (TCO) 的雲端推論。
