# 主要廠商架構分析

本文件詳細分析並比較全球主要 AI 晶片廠商的架構設計理念。隨著生成式 AI 浪潮的推動，各大晶片廠紛紛推出專為大型語言模型 (LLM) 和複雜神經網絡優化的加速晶片，它們在架構選擇、記憶體設計及軟體生態系上各有千秋。

## NVIDIA：軟硬體生態系統的絕對霸主
NVIDIA 在 AI 訓練與推論市場佔據主導地位。其核心優勢在於成熟且難以撼動的 CUDA 軟體生態系與持續演進的 GPU 架構。
- **架構特點**: 從 Ampere 到 Hopper 再到 Blackwell，NVIDIA 持續增強 Tensor Core 的效能，並特別針對 Transformer 架構最佳化（如 Transformer Engine、支援 FP8 / FP4 極低精度運算）。
- **互連技術**: NVLink 提供了極高的晶片間通訊頻寬，這對於由數以萬計的 GPU 組成的超級電腦（用於訓練兆級參數模型）至關重要，有效突破了 PCIe 的瓶頸。

## Google (TPU)：客製化 ASIC 的先驅
Google 的 TPU (Tensor Processing Unit) 是專為深度學習設計的 ASIC 架構，展現了軟硬體極致優化的潛力。
- **架構特點**: 具備強大的矩陣乘法單元（Matrix Multiply Unit），並採用脈動陣列 (Systolic Array) 設計，使得資料在陣列內部流動，大幅減少了記憶體讀寫。
- **軟體生態**: 透過 XLA 編譯器及 HBM 技術達到高頻寬記憶體傳輸效能，在自家的資料中心與雲端服務中展現極佳的能源效率。其超大規模的 TPU Pod 透過光纖環狀拓樸，實現了高效率的分散式訓練。

## AMD：異質整合與開放生態的挑戰者
AMD 以其 CDNA 架構（例如 MI300 系列）在資料中心領域與 NVIDIA 激烈競爭。
- **架構特點**: MI300X 採用了極致的 Chiplet (小晶片) 異質整合技術與 3D 封裝，將 CPU、GPU 和高達 192GB 的 HBM3 緊密結合。其最大的優勢在於提供了業界領先的記憶體容量與頻寬，這對於需要載入龐大權重的 LLM 推論極具吸引力。
- **軟體生態**: 強調開放原始碼的 ROCm 軟體堆疊，正積極縮短與 CUDA 在易用性上的差距。

## Groq：顛覆性的 LPU 確定性架構
Groq 提出了顛覆性的 LPU (Language Processing Unit) 架構，針對推論任務提供了驚人的極低延遲表現。
- **架構特點**: 採用 deterministic（確定性）執行模型，完全捨棄傳統 CPU/GPU 的快取層次結構、硬體排程與分支預測器。
- **記憶體設計**: 利用龐大且極速的晶片內 SRAM 緊密耦合運算單元，雖然單一晶片無法容納超大模型，但透過多晶片互連，在 LLM 推論（如 token 生成速度）上取得了遠超傳統 GPU 的吞吐量，尤其適合對延遲極度敏感的應用。

## Apple：終端裝置與邊緣運算的王者
Apple Silicon (如 M 系列與 A 系列晶片) 整合了強大的 Neural Engine (NPU)，定義了邊緣運算的標竿。
- **架構特點**: 其設計理念著重於終端裝置的低功耗推論。最核心的優勢在於統一記憶體架構 (Unified Memory Architecture, UMA)，讓 CPU, GPU 和 NPU 可以無縫共享同一塊高頻寬記憶體，省去了大量資料複製的延遲與功耗。
- **應用場景**: 使得在行動裝置及個人筆電上流暢運行本地化的 AI 模型成為可能，且擁有業界最頂尖的能耗比。
