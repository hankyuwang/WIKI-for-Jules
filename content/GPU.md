# GPU 架構與應用

## 摘要
GPU（Graphics Processing Unit，圖形處理器）最初專為處理圖形渲染設計，具備高度平行計算能力。隨著 AI 發展，GPU 成為訓練與推理深度學習模型的核心硬體。本篇探討 GPU 的架構方案及其在 AI 領域的應用與權衡。

## 方案與觀點

### 方案一：通用型 GPU (General Purpose GPU, GPGPU)
此方案利用 GPU 大量的串流多處理器（SM）進行通用平行計算，不限於特定的神經網絡運算。
- **優點**：靈活性極高，可支援各種資料類型與自定義演算法，社群生態（如 CUDA）非常完善。
- **缺點**：對於特定張量運算（Tensor Operations）效率不如專用硬體。
- **成本**：研發與生態系統建置成本高，硬體單價不斐。
- **維護性**：軟體生態系成熟，維護相對容易，擁有豐富的工具鏈。
- **風險**：面對針對性極強的新演算法，可能會被專用加速器（如 NPU）在特定場景下取代。

### 方案二：搭載 Tensor Core 的 AI 優化 GPU
在 GPU 中加入專為矩陣乘法設計的 Tensor Core（如 NVIDIA Volta 及後續架構），專攻深度學習運算。
- **優點**：大幅提升 FP16/BF16/INT8 矩陣運算吞吐量，極大加速模型訓練與推理。
- **缺點**：晶片面積增大，功耗極高；僅在矩陣運算時能發揮最大效能。
- **成本**：硬體設計與製造成本極高，導致終端產品售價昂貴。
- **維護性**：依賴廠商提供的特定函式庫（如 cuDNN），若 API 變更可能需要調整軟體。
- **風險**：過度依賴單一廠商（如 NVIDIA）的生態系，可能面臨供應鏈或授權風險。

### 方案三：多 GPU 擴展架構 (Multi-GPU Scale-out)
透過高速互連技術（如 NVLink、PCIe 拓樸）將多個 GPU 串聯，解決單一 GPU 記憶體與算力瓶頸。
- **優點**：能夠訓練和部署超大規模模型（如 GPT-4, Llama-3.1），突破單點限制。
- **缺點**：通訊開銷（Communication Overhead）巨大，架構設計極為複雜。
- **成本**：需要昂貴的網路設備（如 InfiniBand）與伺服器架構，整體建置與運行成本驚人。
- **維護性**：分散式系統維護困難，需要專業的 SRE 與 ML 工程師團隊監控與除錯。
- **風險**：硬體故障率隨數量增加而提升，需具備高度容錯能力的軟體架構設計。
