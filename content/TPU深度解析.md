# TPU 深度解析

張量處理單元 (Tensor Processing Unit, TPU) 是 Google 為了加速機器學習工作負載（特別是基於 TensorFlow 框架）而客製化設計的 ASIC（特殊應用積體電路）。與追求通用性的 [[GPU架構與發展|GPU]] 不同，TPU 被設計來極致優化深度學習中佔據主導地位的矩陣運算。

## TPU 的核心架構：脈動陣列 (Systolic Array)

TPU 設計中最關鍵的特徵是採用了**脈動陣列 (Systolic Array)** 作為主要運算單元（Matrix Multiply Unit, MXU）。
（註：這與 [[NPU架構探索]] 中提到的許多基礎結構概念相似）。

### 運作原理
在傳統的 Von Neumann 架構 CPU 或早期的 GPU 中，每次執行運算指令，ALU（算術邏輯單元）都需要從暫存器或快取中讀取資料，運算後再寫回。這種頻繁的資料搬運消耗了大量的時間和能量。

脈動陣列設計了一組緊密連接的乘加運算器 (MAC) 陣列。資料（權重和輸入特徵）像心跳脈動一樣，規律地從陣列的一端輸入，並在相鄰的 MAC 單元之間傳遞。
- **權重複用**：模型的權重被載入到 MAC 陣列中並保持不變。
- **資料流動**：輸入資料沿著陣列流動，逐步與每一層的權重相乘並累加結果。

這種設計極大地減少了對外部記憶體 (SRAM/DRAM) 的存取次數，大幅提高了運算效率和能耗比。

## TPU 的演進

1. **TPU v1**：主要專注於神經網絡的**推論 (Inference)**。採用 INT8 整數運算（與 [[模型量化技術]] 高度相關），提供極高的推論吞吐量。
2. **TPU v2/v3**：加入了對浮點數 (bfloat16) 的支援，開始跨足**訓練 (Training)** 領域。這些版本也引入了高頻寬記憶體 (HBM) 以及專用的互連網路 (Torus 拓撲)，使得多個 TPU 可以組成 TPU Pod，進行大規模的分散式訓練。
3. **TPU v4、v5及Trillium 更新版本**：進一步提升了互連頻寬、HBM 容量和運算效能，專為訓練超大型語言模型 (LLM) 和推薦系統而設計。

## 與其他加速器的比較

相對於 [[GPU架構與發展|GPU]]，TPU 在處理大規模矩陣運算時擁有更高的效能功耗比，且在大規模叢集訓練 (TPU Pods) 的網路拓撲設計上有其獨到之處。但其靈活性不如 GPU，生態系統主要綁定 Google Cloud 和 JAX/TensorFlow。
