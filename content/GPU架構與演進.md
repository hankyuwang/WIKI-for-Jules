# GPU 架構與演進

摘要：GPU（Graphics Processing Unit）最初設計用於圖形渲染，但其高度平行化的架構使其成為現代人工智慧與深度學習運算的核心。本文探討 GPU 架構的演進，以及在面對不同應用場景時的幾種解決方案視角。

## 方案視角一：通用 GPU (GPGPU) 擴展
將 GPU 設計為更通用的計算平台（如加入 Tensor Core 專門處理矩陣運算）。
- **優點**：高度靈活性，能適應多樣化的 AI 模型與演算法。
- **缺點**：晶片面積增加，可能有較高的功耗。
- **成本**：研發與製造成本極高。
- **維護性**：軟體生態系成熟（如 CUDA），維護相對容易。
- **風險**：若有特定的新興演算法突破，可能面臨效能被專用晶片超越的風險。

## 方案視角二：專精於特定運算精度 (如 FP8/INT8)
為了追求極致效能，現代 GPU 架構越來越強調低精度運算的支援。
- **優點**：在相同的硬體資源下，大幅提升吞吐量並降低記憶體頻寬需求。
- **缺點**：模型可能需要重新訓練或進行量化處理，影響模型精確度。
- **成本**：需要硬體與軟體編譯器的同步升級。
- **維護性**：需要維護量化工具鏈與硬體支援的對齊。
- **風險**：若未來模型對高精度需求提升，低精度設計可能會面臨適用性問題。

## 方案視角三：多 GPU 互連架構 (NVLink / NVSwitch)
透過高速互連技術，將多顆 GPU 連結為一個龐大的運算叢集。
- **優點**：能夠訓練超大規模模型，打破單顆 GPU 的記憶體限制。
- **缺點**：系統複雜度倍增，帶來額外的延遲挑戰。
- **成本**：基礎設施與互連硬體成本極為昂貴。
- **維護性**：資料中心級別的維護，需要專業的硬體與網路團隊。
- **風險**：網路瓶頸可能成為系統整體效能的最大限制。
