# 反向傳播 (Backpropagation)

摘要：反向傳播是神經網路訓練的核心演算法，透過微積分中的連鎖律 (Chain Rule)，由輸出層往回計算損失函數對每一個權重的梯度，進而指導模型更新。

## 已知事實
反向傳播需要保留前向傳播 (Forward Pass) 產生的中間啟動值 (Activations)，因為計算梯度時會用到這些數值。這正是導致模型訓練時記憶體需求遠大於推論 (Inference) 的根本原因。

## 原理
訓練過程分為兩步：首先前向傳播計算出預測值與損失 (Loss)。接著，反向傳播從損失函數出發，利用連鎖律逐層計算偏導數。這個過程本質上是一連串密集的矩陣乘法與轉置運算。

## 限制
隨著網路深度增加，反向傳播容易遇到梯度消失 (Vanishing Gradient) 或梯度爆炸 (Exploding Gradient) 的問題，使得靠近輸入層的權重難以有效更新。此外，它是一個嚴格循序 (Sequential) 的過程，後一層的梯度計算必須等待前一層完成，限制了平行化程度。

## 未知問題
生物大腦的學習機制並不完全依賴嚴格的反向傳播。學界一直在探索更符合生物學 (Biologically Plausible) 或能在硬體上進行本地學習 (Local Learning) 的替代演算法，如 Hebbian Learning 或 Forward-Forward Algorithm。

## 最佳實務
採用殘差連接 (Residual Connections) 和正規化技術 (如 Layer Normalization) 能有效緩解深層網路中反向傳播導致的梯度不穩定問題。

## 方案與觀點分析

### 方案一：標準反向傳播與混合精度訓練 (Mixed Precision)
- 優點：利用 Tensor Core 硬體加速矩陣乘法，同時維持收斂穩定性。
- 缺點：仍需要大量記憶體來儲存啟動值。
- 成本：低，主流框架皆有內建支援 (如 PyTorch AMP)。
- 維護性：高。
- 風險：處理極深或不穩定模型時，可能遭遇數值溢位 (Overflow/Underflow)。

### 方案二：啟動值重算技術 (Activation Checkpointing / Gradient Checkpointing)
- 優點：用「計算時間」換取「記憶體空間」。在前向傳播時不保存所有中間啟動值，而是在反向傳播需要時重新計算，可省下巨量記憶體。
- 缺點：整體訓練時間會增加約 20%~30%。
- 成本：低 (軟體配置)。
- 維護性：高。
- 風險：運算瓶頸過於嚴重時，可能導致 GPU 算力無法被其他並行任務充分利用。

### 方案三：管線平行 (Pipeline Parallelism) 配合微批次
- 優點：打破單機限制，將模型的不同層分佈在多台機器上，反向傳播的計算像工廠流水線一樣傳遞。
- 缺點：引入了「管線氣泡」(Pipeline Bubbles) 導致硬體閒置，排程極度複雜。
- 成本：極高，需要高速網路基建 (如 InfiniBand)。
- 維護性：低，除錯困難。
- 風險：節點間的網路延遲若過高，將抵銷平行化帶來的效能增益。
