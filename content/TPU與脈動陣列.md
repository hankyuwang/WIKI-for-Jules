# TPU 與脈動陣列 (Systolic Array)

TPU (Tensor Processing Unit) 是 Google 專為神經網路推論與訓練開發的客製化 ASIC 加速器。與通用 GPU 相比，TPU 放棄了許多為了圖形處理而保留的複雜控制邏輯，轉而極大化晶片上的乘累加單元 (MAC)。

TPU 的核心架構是**脈動陣列 (Systolic Array)**。這是一種高度規則的計算節點網路，資料像是血液在心臟的脈動中一樣，以固定的節奏 (Clock) 規律地流經各個運算單元。這種設計極大地減少了存取記憶體 (SRAM/DRAM) 的次數，因為運算結果會直接傳遞給陣列中的下一個單元，非常適合神經網路中龐大的稠密矩陣乘法。

## 解決方案觀點：脈動陣列的優化方向

儘管脈動陣列在稠密矩陣運算上表現優異，但隨著模型發展，業界提出不同的改進方案以解決其固有的限制：

### 1. 支援稀疏矩陣 (Sparsity) 的脈動陣列

傳統脈動陣列在遇到包含大量 0 的稀疏矩陣時，會執行大量的無效運算（0 乘任何數還是 0）。此方案透過硬體機制跳過零值的運算。

- **優點**：大幅提升實際運算效能並降低功耗，特別是在經過剪枝 (Pruning) 的模型上效果顯著。
- **缺點**：硬體設計變得很複雜，需要額外的控制邏輯與記憶體頻寬來處理不規則的資料流。
- **成本**：硬體設計成本上升，且需要強大的編譯器支援。
- **維護性**：軟硬體協同設計難度高，需要特定的算子庫支援，維護負擔較重。
- **風險**：如果模型不夠「稀疏」，或者稀疏分佈過於隨機，額外的控制邏輯反而會造成效能倒退 (Overhead)。

### 2. 多維度彈性脈動陣列

將單一巨大的脈動陣列（例如 256x256）拆分為多個較小、可獨立或協同工作的子陣列。

- **優點**：提高了晶片利用率。當遇到維度較小或形狀奇特的矩陣時，不會造成大量 MAC 單元閒置。
- **缺點**：增加了子陣列之間的路由 (Routing) 複雜度與同步開銷。
- **成本**：互連網路 (Interconnect) 的設計與佈線成本增加。
- **維護性**：編譯器需要具備將大型任務智能切割排程到不同子陣列的能力，維護難度中偏高。
- **風險**：子陣列間的資料搬移若設計不當，可能成為新的效能瓶頸。

### 3. 混合精度 (Mixed-Precision) 脈動陣列

同一個硬體陣列可以根據指令，動態切換計算精度（例如將一個 INT16 的乘法器拆分為兩個 INT8 的乘法器）。

- **優點**：提供了極大的靈活性，能同時兼顧需要高精度（如某些層的梯度累積）與低精度（如前向傳播）的場景。
- **缺點**：增加了硬體電路的複雜度與面積。
- **成本**：晶片製造成本微幅上升，但能透過提高通用性來攤提。
- **維護性**：軟體層面需要能自動判定各層適合的精度（Auto Mixed Precision），對底層函式庫開發者是一大挑戰。
- **風險**：硬體支援多種模式可能導致編譯器的優化空間過於龐大，難以找到最佳的排程策略。
