# NVLink

摘要：NVLink 是由 NVIDIA 開發的專有高速點對點互連技術，旨在解決多 GPU 系統中 PCIe 總線頻寬不足的瓶頸。透過 NVLink，GPU 之間可以實現極低延遲、超高頻寬的資料共享。

## 為什麼需要 NVLink？
在傳統的多 GPU 系統中，GPU 之間以及 GPU 與 CPU 之間的資料交換主要依賴 [[PCIe]] 總線。然而，隨著 AI 模型的指數級增長，模型並行和數據並行訓練需要 GPU 之間頻繁交換海量的梯度與權重資料。PCIe 的頻寬已經無法滿足這種需求，成為了系統效能的瓶頸。NVLink 的出現正是為了解決這個「互連牆」的問題，它提供了一條 GPU 之間的「高速公路」，繞過 PCIe 瓶頸。

## NVLink 的技術演進與頻寬
NVLink 自推出以來，頻寬經歷了顯著的提升：
* **第 1/2 代 (Pascal/Volta)**：雙向總頻寬達到 160~300 GB/s。
* **第 3 代 (Ampere 架構, 如 A100)**：雙向總頻寬躍升至 600 GB/s。
* **第 4 代 (Hopper 架構, 如 H100)**：雙向總頻寬達到驚人的 900 GB/s，比 PCIe Gen5 x16 的頻寬高出數倍。
* **第 5 代 (Blackwell 架構, 如 B200)**：進一步提升雙向總頻寬至 1.8 TB/s。

## NVSwitch 與多 GPU 叢集架構
早期的 NVLink 主要是 GPU 之間的直接點對點連接。為了解決多個 GPU 間的全互連複雜度，NVIDIA 引入了 **NVSwitch** 晶片。NVSwitch 類似於網路交換機，但專門用於路由 NVLink 訊號。
* **單節點內部**：8 張 GPU 透過底板上的多顆 NVSwitch 進行全互連，任何兩張 GPU 之間都能以全速 NVLink 頻寬通訊。
* **跨節點擴展**：透過外接的 NVSwitch 交換機系統，可以將伺服器節點連接成一個巨大的 GPU 叢集，讓整個叢集運作起來就像一顆超級 GPU。這支持了統一記憶體存取，大幅簡化了分散式程式設計的複雜度。

## 方案與觀點分析

### 方案一：全面採用 NVLink 與 NVSwitch 叢集 (NVIDIA 封閉生態)
- 優點：業界頂尖的互連頻寬，極大化大型模型訓練效能。
- 缺點：硬體成本極為高昂，且被 NVIDIA 生態深度鎖定。
- 成本：極高
- 維護性：高
- 風險：供應商單點故障與定價權掌控風險。

### 方案二：採用 PCIe Gen5/Gen6 搭配高效能網卡 (標準化方案)
- 優點：基於開放標準，成本較低，硬體選擇多樣化。
- 缺點：節點內 GPU 互連頻寬遠不及 NVLink，會成為超大模型訓練瓶頸。
- 成本：中等
- 維護性：中高
- 風險：效能無法達到頂尖水準。

### 方案三：投資開放互連標準 (如 CXL / UALink)
- 優點：打破專有協議限制，長期有望實現跨廠商加速器的資源池化。
- 缺點：生態系與硬體支援尚在發展初期。
- 成本：長期研發成本高
- 維護性：中等
- 風險：標準推廣落地不如預期。
